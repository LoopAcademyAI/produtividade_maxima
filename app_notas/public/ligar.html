Ligar ao Entrelinhas

Gera o teu URL pessoal. Quem o tiver pode usar o teu acesso: não o partilhes nem o guardes num repositório.

Uma nova chave para o mesmo nome invalida a anterior. A ligação depende do servidor MCP do Grupo 4 e da compatibilidade do teu assistente.

Para Claude Code: claude mcp add --transport http entrelinhas "O_TEU_URL". Nos outros clientes, procura adicionar servidor MCP HTTP e usa configuração pessoal, nunca versionada.
